## CONTEXTO DE LA PRUEBA
Usted es el UX Engineer responsable de mejorar el aplicativo institucional denominado "Usability Test Dashboard 2.0". El sistema presenta problemas de experiencia de usuario, navegación y organización visual. El estudiante deberá aplicar principios HCI, UX y Scrum para identificar problemas, rediseñar una funcionalidad crítica y evidenciar todo el proceso mediante GitHub.

## OBJETIVO GENERAL
Aplicar principios de Interacción Humano Computador, usabilidad, evaluación heurística, arquitectura de información, wireframes y diseño UX mediante mejoras reales sobre el aplicativo "Usability Test Dashboard 2.0", utilizando Scrum y control de versiones GitHub.

---

## FASE 1: PLANIFICACIÓN SCRUM
Crear dentro del repositorio una carpeta denominada HCI-PruebaFinal. Desarrollar:
* Product Backlog
* Sprint Planning
* User Stories
* Priorización de tareas
* Evidencia Scrum

## FASE 2: EVALUACIÓN HEURÍSTICA
Aplicar evaluación heurística al aplicativo en:
* Login
* Dashboard
* Formularios
* Navegación
* Reportes

Detectar mínimo 10 problemas UX clasificados como:
* Críticos
* Moderados
* Leves

## FASE 3: REDISEÑO UX
Seleccionar una pantalla crítica del Dashboard y mejorarla aplicando:
* Leyes de Gestalt
* Jerarquía visual
* Arquitectura de información
* Navegación contextual
* Prevención de errores
* Diseño emocional

Construir Wireframes:
* Lo-Fi
* Mid-Fi
* Hi-Fi

## FASE 4: IMPLEMENTACIÓN FUNCIONAL
Implementar una mejora UX real dentro del sistema. Ejemplos:
* Breadcrumbs
* Stepper
* Validaciones
* Mensajes dinámicos
* Barra de progreso
* Navegación contextual
* Feedback visual

## FASE 5: EVIDENCIA IA
Documentar:
* Prompts utilizados
* Herramienta IA usada
* Resultado obtenido
* Cómo ayudó en el diseño UX

## FASE 6: GITHUB Y CONTROL DE VERSIONES
El estudiante debe evidenciar mínimo 5 commits reales relacionados con:
* Evaluación heurística
* Wireframes
* Rediseño UX
* Implementación funcional
* Documentación
