# HCI-PruebaFinal — Usability Test Dashboard 2.0

## 📝 Descripción del Proyecto
Este repositorio contiene la resolución del examen final de la asignatura Interacción Humano / Computador. Se ha realizado una mejora integral del sistema "Usability Test Dashboard 2.0", aplicando principios de HCI, UX y metodologías ágiles.

## 🚀 Fases del Examen

### 1. Planificación Scrum
*   **Backlog:** Ubicado en `product_backlog.md`.
*   **Sprint:** Ubicado en `sprint_planning.md`.
*   Se definieron User Stories centradas en la reducción de la carga cognitiva del investigador.

### 2. Evaluación Heurística
*   Se identificaron **10 problemas críticos/moderados** utilizando las Heurísticas de Nielsen.
*   Documento detallado: `heuristic_evaluation.md`.

### 3. Rediseño UX y Wireframes
*   Se aplicaron las **Leyes de Gestalt** (Proximidad, Región Común) para reestructurar el Dashboard.
*   Wireframes disponibles en formato Mermaid.js dentro de `wireframes/rediseño_ux.md`.

### 4. Implementación Funcional
*   **Mejora:** Se implementaron **Breadcrumbs Dinámicos** para mejorar la navegación contextual y el control del usuario.
*   **Ubicación:** `src/presentation/components/ui/Breadcrumbs.tsx`.

### 5. Evidencia IA
*   Se utilizó **Gemini CLI** como asistente de ingeniería para acelerar la documentación y el rediseño.
*   Detalles en: `ai_evidence.md`.

## 🛠️ Tecnologías Utilizadas
*   React 19 + TypeScript
*   Tailwind CSS
*   Lucide React (Iconografía)
*   GitHub (Control de versiones)
